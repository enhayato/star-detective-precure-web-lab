关于本站

把散落在不同日期、不同地区的探Q活动线索整理起来，让没有亲自到场的粉丝，也能重新认识2026年的活动足迹。

这是什么网站？

本站是由粉丝独立制作的 《名探偵プリキュア！》2026年活动回忆档案，并非动画官方、制作方或活动主办方运营的网站，也不代表他们的声明或认可。

它关注已发生的公开活动与联动信息，主要用于事后浏览、寻找线索和保存回忆；不提供实时活动情报、购票、预约、报名或现场导航。

可以在这里发现什么？

可以从三个方向寻找已收录记录：通过日历回看日期，通过地区示意地图挑选地点，通过活动档案列表筛选已收录条目，并从活动卡片进入对应的纪念册。

目前地图的全国层级包含47个都道府县，东京可进一步选择62个区市町村。方块排列是便于浏览的示意布局，不代表真实行政边界、面积、距离或精确相邻关系。

收录范围与现在的进度

本站计划逐步整理与2026年《名探偵プリキュア！》相关、可以追溯公开资料的活动及联动。具体纳入哪些活动类别、如何划分同一活动的不同举办场次，仍需进一步确定。

当前仍是演示原型：日历、地图、档案列表和纪念册目前仅共享一条2026年10月15日新宿 Staff Talk 的演示记录。这条资料尚未完成对外发布所需的全部独立核查；正式活动数据库未接入。

没有显示某一天、某个地区的记录，只表示本站在当前筛选条件下没有已收录资料，不意味着当时、当地没有举办活动。 页面不应被当作日本全国活动的完整统计。

资料与图片如何处理？

  • 正式收录前，优先核对官方、主办方、场馆等能直接确认事实的公开资料；转发和二次报道可作为寻找原始来源的线索。
  • 区分公告发表日期、实际举办日期及举办场次与地点；多日、多地、延期、取消和修订不能简单混在同一项计数中。
  • 公开展示的信息应标明可核查的来源与已知限制；无法核实的细节宁可暂不展示，不以推测补齐。
  • 活动海报、现场照片和官方角色图片不因网上可以看到就默认可以转载；在确认相应使用条件前，纪念册可继续采用无图样式。

以上为逐步完善正式收录时遵循的处理原则，并非声称现有演示记录已经全部核验完毕。

发现遗漏或错误怎么办？

如果发现日期、地点、活动名称或来源有误，或者掌握本站尚未收录的公开活动线索，可以通过本仓库的 GitHub Issues 提出，通常需要登录 GitHub 账号。

提供活动名称、相关日期与地点、原始公开来源链接、需要新增或更正的具体内容，有助于后续核查。请不要提交电话号码、住址等与活动核证无关的个人信息。

提出线索不代表自动收录或立即更正；资料仍须核对来源及公开使用条件。本站目前没有单独的在线投稿表单，也不承诺固定的处理时限。

接下来会怎样？

目前优先完善基本浏览体验、收录规则与可公开使用的正式活动资料。关于更多地图展示和长期扩展，仍以以后明确的开发决定为准；不会把尚未决定的构想说成已经上线的功能。
