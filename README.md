# Star Detective Precure Web Lab

A practice repository for learning GitHub and building a prototype event website for Star Detective Precure.

## Project Goals

- Learn GitHub version control.学习GitHub版本控制
- Build a simple website using HTML, CSS, and JavaScript.在Git里创建一个简单的网页，包括HTML CSS Javascript
- Display event information from JSON files.让网站显示JSON文件里的信息
- Publish the website using GitHub Pages.将网站通过GitHub Pages公开

## Current Status

Learning GitHub basics. The website has not been developed yet.
