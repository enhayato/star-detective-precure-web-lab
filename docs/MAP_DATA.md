# 地图数据、出典与使用边界｜MAP_DATA

## 0. 目的与状态

此目录用于《探Q活动回忆档案馆》日本行政区地图 **原型**。目前仅有全国47都道府县与东京都62个区市町村的简化可视化边界；不代表已完成全国市区町村覆盖、地图授权终验或2026年边界复核。本文件与 `docs/UI_DESIGN_V1.2.md` 配套，后续地图资料升级须同步修改这两处的当前状态及 README。

- 本轮工作分支：`feature/map-v1-2-prototype`。
- 仅新增 `map.html` 及本地数据文件，**不在此分支覆盖线上日历**。合并前，GitHub Pages 上的 `main` 仍没有本地图。
- 原型测试事件：2026-10-15 新宿バルト9 Staff Talk（内部史料已定位，**未作为正式公开数据核验完成**）。紫色仅用于演示筛选，不能推算2026年各地活动覆盖率。

## 1. 原始来源及许可线索

本地两个简化文件来自以下公开数据的衍生链：

1. **日本国土交通省国土数值情報** `N03 行政区域数据 2025年版`（非2026年版）。原始行政区数据按2025-01-01基准编制。源页面：<https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-2025.html>。
2. **一般社团法人共同通信社** 的开源地图数据工程 `japan-choropleth`，基于上述2025版 N03 进行加工，保存 `data/topojson/prefectures.topojson` 及 `data/topojson/by-prefecture/13/municipalities.topojson`。仓库：<https://github.com/kyodo-official/japan-choropleth>。仓库说明：脚本为 MIT，但地图多边形数据不适用 MIT，而应遵循原始地理数据的许可条件。
3. **本项目**（二次加工）：从上述 TopoJSON 解码共同边界，使用 Ramer–Douglas–Peucker 简化弧线，生成适合 GitHub Pages 的 SVG 路径 JSON。没有把共同通信的 JavaScript 运行时代码打包进来。

**出典／归属：**「国土交通省 国土数値情報『行政区域データ（2025年版）』を加工。共同通信社『japan-choropleth』の加工済みポリゴンをもとに当サイトがさらにSVG用に簡略化。」原始数据页注明 CC BY 4.0。许可证介绍：<https://creativecommons.org/licenses/by/4.0/>。

**待核的法律边界：** MLIT N03 页面提示，二次利用时有时需要依照《测量法》向国土地理院办理申请。该网页是非测量、非导航的卡通化行政范围可视化，并不因此自动证明所有利用条件已满足。正式大范围公开和数据更新前，应按实际展示及分发方式对照国土地理院的「地図の利用手続ナビ」再次确认是否属于无需申请情形；若结果显示需要申请，先完成许可手续。参见：

- <https://www.gsi.go.jp/LAW/2930-index.html>
- <https://service.gsi.go.jp/onestop/navi/index/>
- <https://nlftp.mlit.go.jp/ksj/other/agreement.html>

**版本说明：**截至2026年11月，MLIT 已有 N03 **2026年1月1日版**；本演示采用 2025版的第三方加工几何，不能标记为「最新2026官方行政边界」。后续可以用2026官方源重新制作同一格式的数据，核对边界变更及出典条件；不得无记录地替换。

**对原始数据所做的变更：**

- 单位经纬度按网页内嵌规则投影：SVG `x = longitude × 100`，`y = -latitude × 100`。这是绘图坐标而非测量精度保证。
- 对弧线进行 RDP 简化，预设公差：全国府县约 `0.009°`，东京区市町村约 `0.0007°`；点坐标格式保留绘图单位一位小数。
- 为让手机与静态网站能显示，删除部分过小的独立环：全国最大经纬跨度低于 `0.012°`、东京低于 `0.0016°` 的环被跳过。故**极小离岛可能不显示**，不得把缺失环解释为该岛不存在或不属某行政区。
- 东京源包含一条 `13000 / 所属未定地` 的非正式市区町村示例单元，未作为区市町村展示；剩余62条分别保留真实代码与名称。
- 全国本州、北海道、九州、四国等主体按主要地图画幅显示，冲绳使用地图内嵌缩略窗。部分偏远岛屿可能落在主画幅以外；东京第2级按本土、伊豆诸岛、小笠原诸岛切换同一级地理视图，并不是另外创造的行政分区。
- 网页导出的路径有共享弧线来源，但经过简化、显示裁切及绘图变换，**不用于测距、导航、地籍或行政权界精密认定**。

## 3. 客户端地图语义

- 没有示例记录的区域始终使用深灰色；有示例记录的区域使用紫色并可轻柔发光。不同亮色的分级规则**尚未批准**，因此原型不使用粉／蓝代表某种活动数量。
- 点击全国都道府县高亮选择；只有东京下钻到62个真实行政单元。其他都道府县目前只可选择、不能进入虚构的第2级。
- 东京原型覆盖本土区市町村、伊豆诸岛和小笠原诸岛；每个区市町村有可供触屏使用的替代下拉菜单。因为缩放与小岛裁切，**选单比地图更能确保每个行政单元都可选中**。
- 选中状态不等于有活动；当前无演示记录不等于2026年未举办过活动。
- 仅一条内部史料导航定位的 Staff Talk 用于点击筛选样例，不与正式研究库同步。

## 4. 地图验收与后续任务

地图 PR 的合并前人工核验应覆盖：

- 全国恰好47个都道府县，东京恰好62个真实区市町村单元；核对东京主要区位关系和代表性行政代码。
- 电脑与 iPhone 上的点击、下拉替代选择、缩略窗、各离岛视图与返回全国。
- 日期 `2026-10-15` / 其他日期 / 整月切换后，东京及新宿区的示例高亮符合演示记录。
- 选择无收录记录地区时展示「暂无已收录」，不写成「当地没有活动」。
- 页面刷新、浏览器后退、从地图返回日历可保持日期条件。
- 检查实际资源大小、加载失败提示、来源归属和使用限制。
