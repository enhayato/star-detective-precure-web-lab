# 演示活动数据与纪念册原型｜EVENT_DATA

## 用途与边界

本文件说明 PR #7 的静态演示数据，不是正式活动数据库架构，也不取代内部产业研究数据库。唯一演示数据为 `data/events-demo.json`；日历、地图及详情页都通过 `fetch("./data/events-demo.json")` 读取同一文件。

当前只含一条 2026-10-15 Staff Talk 演示记录，日期、地点在现有内部访谈资料中已定位，但官方公告、具体时刻、出演细节及图像版权尚未做对外发布级复核。空缺不应自行补造。

## 当前字段说明

| 字段 | 用途 |
| --- | --- |
| `id` | 详情页 URL 稳定标识 `?id=` |
| `title`, `start`, `end` | 活动名、首尾日期；ISO `YYYY-MM-DD` 日本当地历日，日期范围包含端点 |
| `prefecture` | 日历粗地区值（`tokyo`／`other`） |
| `pref`, `muni` | 地图行政编码，例如东京 `13`、新宿区 `13104` |
| `regionName`, `venue` | 地点显示文字与场馆 |
| `category`, `categoryName` | 类型筛选编码与展示名 |
| `summary`, `note` | 对外简述与当前核证限制 |
| `imageUrls`, `sourceLinks`, `relatedIds` | 预留扩展位，当前空数组；不能据此判断史料或关联活动不存在 |

当前页面使用 `textContent` 设置可变文字，避免直接拼接外来 HTML。图片、来源及关联列表暂保持明确占位，不自动公开数组中的未经核验内容。

## 导航与返回

日历／地图活动预览增加 `event.html?id=...` 链接，并携带 `from=calendar|map`、月份、单日／整月、日期、类型及原页面地区参数。详情页显式返回链接只指向本站固定 `index.html` 或 `map.html`，不会接受任意外站跳转地址；返回原页后由现有 URL 状态逻辑还原筛选。若同站来源可靠，历史返回按钮调用 `history.back()`，尽量维持原滚动位置；直达页面则使用固定返回链接。

## 正式接入前待审批

1. 从研究库筛选公开可用资料，独立核对官方公告、发生日期、地点及具体信息。
2. 确认原始海报、照片的公开再利用权限；尚未确认时维持无图封面。
3. 批准「活动主档／举办场次及地点／公开展示视图」模型，处理跨日、异地多场与计数去重，不能将本演示 JSON 当成最终正式 schema。
4. 合并后按 PC 与 iPhone 验证单日／整月、日期及地区筛选、返回与刷新、直达详情和无匹配 ID、JSON 加载错误。
